A personal health and medication management app where users sign up, add and edit their medications, track active vs. discontinued medications with full date history, and manage their profile (edit details, change password) — all backed by a real Express/MongoDB API with JWT authentication. 

Frontend: React Native (Expo), TypeScript, Expo Router; Styling: React Native StyleSheet; State Management: Context API; Authentication: JWT (email/password) with Expo SecureStore for token persistence; Backend: Node.js, Express.js, TypeScript; Database: MongoDB
